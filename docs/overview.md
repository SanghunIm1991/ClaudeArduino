# 概要資料 — 前提条件の確認（2026-08-30時点）

このドキュメントは、プロジェクト開始にあたりClaudeが理解した前提条件をまとめたものです。認識違いがあれば指摘してください。

## 1. 目的

AIエージェント（Claude Code）を活用した組み込み開発の可能性を調査する。生産用ソフトウェアの開発ではなく調査目的のため、正式な工程管理（要件定義→設計→実装→テストのゲート承認等）は導入せず、**軽量な進め方**を採用する。セッションごとに段階的に作業を進め、都度この種の概要資料やコードレビューを挟んで認識をすり合わせる。

備考: 付属LEDは1kΩ抵抗で点灯確認済みとのことだが、LEDは3種類（色・順方向電圧が異なる可能性）あり、330Ω・270Ωの抵抗も同梱されている。どのLEDにどの抵抗を組み合わせるかは、実際に回路図を作成する回（プログラム②以降）で個別に電圧・電流計算を行って決定する。

### 2.3 役割分担

- **配線・ブレッドボード組み立て（実際の電気工作）はユーザーが行う。**
- **Claudeは回路図を作成する。** 回路図はmermaid記法で表現し、電圧・電流の計算（オームの法則による抵抗値・電流の妥当性確認など）を必ず添える。

## 4. 進め方（今後作成予定のプログラム）

調査目的のため、複数の小さなプログラムを段階的に作成する。現時点の構想:

| # | 内容 | 電気工作 |
|---|---|---|
| ① | シリアル通信のみ | なし（USB接続のみ） |
| ② | 単純なタクトスイッチとLED | あり（スイッチ入力→LED出力） |
| ③ | お任せ（内容はClaudeが提案） | 未定 |

各プログラムは `programs/<番号>_<内容>/` 以下にPlatformIOプロジェクトとして配置する想定（例: `programs/01_serial_only/`）。①から順に、1セッションずつ進める想定でよいか確認したい。

## 5. 確認結果（2026-08-30 ユーザー回答）

- ①「シリアル通信のみ」: Arduino→PCへの定期送信という理解で正しい。**ボーレートは実機で動作するものをClaudeが調査・選定する**（プログラム①作成セッションで確定する）。
- ③「お任せ」: キットの部品（未使用のCdSセル・MOS-FET・ダイオードを含む）で何が作れるか、**Claudeの提案力・実装力を見る**ことが目的。自由度は高め。
- Git運用: **GitHub上に公開（Public）リポジトリを作成しpushする**。
